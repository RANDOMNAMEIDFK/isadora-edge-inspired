# Isadora's Edge Inspired - 2D Metroidvania Game

A high-skill 2D action platformer inspired by Isadora's Edge by InboundShovel, featuring intense combat, exploration, and tight controls.

## Features

- **Fast-paced combat system** with responsive dashing mechanics
- **Exploration-based level design** with secrets and platforming challenges
- **High-skill platforming** requiring precision timing
- **Sci-fi/fantasy aesthetic** with alien world atmosphere
- **Multiple abilities and upgrades** to discover
- **Boss encounters** with unique attack patterns

## Getting Started

### Prerequisites
- Godot 4.x
- Git

### Installation

```bash
git clone https://github.com/RANDOMNAMEIDFK/isadora-edge-inspired.git
cd isadora-edge-inspired
```

Open the project in Godot 4.x

### Project Structure

```
project_root/
├── scenes/              # Game scenes and UI
├── scripts/             # GDScript code
├── assets/              # Sprites, sounds, music
├── levels/              # Level data
└── project.godot        # Godot project configuration
```

## Gameplay

### Core Mechanics
- **Dash** - Quick movement ability (frame-perfect timing encouraged)
- **Combat** - Light and heavy attacks
- **Platforming** - Wall slides, air dashes, environmental interactions
- **Exploration** - Find secrets and unlock new abilities

### Controls
- **WASD/Arrow Keys** - Movement
- **Space** - Jump
- **Shift** - Dash
- **Mouse/Gamepad** - Attack/Interact

## Development

This project is built with:
- **Godot 4.x** - Game engine
- **GDScript** - Scripting language
